What are Class Diagrams?

Wikipedia Article

A UML (Unified Modeling Language) class diagram is a type of static structure diagram that describes the structure of a system by showing its classes, their attributes, methods, and the relationships among objects. In the context of Adjustability, UML class diagrams can be particularly useful because they can visually represent the design of the mod.
